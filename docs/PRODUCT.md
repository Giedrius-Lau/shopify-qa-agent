# Product

## Vision

Shopify QA Agent helps Shopify developers, agencies, and e-commerce teams find actionable storefront defects before shoppers do.

The long-term product can become an installable Shopify app. The MVP scans public storefront URLs without Shopify OAuth.

## Core workflow

1. Enter one or more storefront page URLs.
2. Select desktop, mobile, or both viewports.
3. Run deterministic browser checks.
4. Review evidence-backed issues grouped by severity.
5. Use AI later to explain verified findings and suggest remediation.

## Product principles

- The rule engine establishes facts; AI never invents defects.
- Every issue must include reproducible evidence.
- Shopify-specific interaction checks are the primary differentiator.
- Validate scanner usefulness before investing in SaaS infrastructure.
- Scanning arbitrary URLs must be bounded and secure by default.

## Primary users

- Shopify developers validating theme changes.
- Agencies auditing client storefronts.
- E-commerce teams checking releases and recurring regressions.

## Non-goals for the initial MVP

- Shopify Admin embedding and OAuth.
- Billing, teams, scheduled scans, and private storefront authentication.
- Full performance profiling or visual regression.
- AI-based screenshot interpretation.
